# stock -- 库存管理

## 1. 核心概念

### 库存唯一性

每条库存记录由 **SKU + 仓库 + 库位号** 三元组唯一确定。同一个 SKU 在不同仓库或不同库位中视为不同的库存记录。

### 默认仓库

新增库存时如果省略仓库 ID，系统自动将库存入到**临时仓库**。后续可根据需要迁移到正式仓库。

### 拆分包装

支持将大包装拆分为小包装，例如 1 箱拆成 10 个。拆分后原库存数量减少，新库存记录以目标单位生成。

### 自动拆分

根据需求数量，系统自动从合适的库存中拆分出所需数量，无需手动指定源库存。

### 临期 / 超龄转移

临期（即将过期）和超龄（存放超过 60 天）的库存转移操作**只移动库位**，不改变库存数量和 SKU。用于将问题库存从正常库位移至临期/超龄专区进行管理。

---

## 2. 常用操作

### 2.1 库存新增与查询

```bash
# 新增库存（自动入临时仓库）
stock add

# 查询库存列表（支持 sku / warehouseId 等筛选条件）
stock list

# 查询交易信息
stock buy-info
```

### 2.2 拆分包装

```bash
# 手动拆分：指定源单位、目标单位和拆分数量
stock switch-unit --from <源单位> --to <目标单位> --quantity <数量>

# 自动拆分：按需求数量自动从合适库存拆分
stock auto-split --demand-qty <需求数量> --sku <SKU>
```

示例：将 1 箱（10 个）拆分
```bash
stock switch-unit --from 箱 --to 个 --quantity 10
```

### 2.3 临期 / 超龄管理

```bash
# 查询临期库存
stock expired

# 查询超龄库存（存放超过 60 天）
stock over-60-days

# 转移临期库存到临期专区
stock move-expired

# 转移超龄库存到超龄专区
stock move-over-60-days
```

### 2.4 仓库管理

```bash
# 查看仓库列表
stock warehouses

# 查看仓库详情
stock warehouse-detail

# 新增仓库
stock add-warehouse

# 删除仓库
stock delete-warehouse
```

## 3. 数据校验

新增或操作库存后，按以下步骤验证：

1. **验证库存记录**：
   ```bash
   stock list --sku <SKU>
   ```
   确认新增的库存记录存在，三元组（SKU + 仓库 + 库位号）正确。

2. **拆分后验证**：
   - 源库存数量已减少对应数量。
   - 新库存记录以目标单位存在，数量正确。
   - 总数量守恒：拆分前总数量 = 拆分后各记录数量之和（换算为同一单位后）。

3. **转移后验证**：
   - 原库位库存已减少/清空。
   - 目标库位新增对应记录。
   - SKU 和数量不变，仅库位号变更。

4. **关键提醒**：
   - 新增库存时如果未指定仓库，确认是否已自动进入临时仓库。
   - 临期/超龄查询返回空结果 = 当前无需处理，不是异常。

## 4. 常见错误

| 错误现象 | 原因 | 解决 |
|----------|------|------|
| 拆分时报"库存不足" | 拆分数量大于源库存当前数量 | 检查源库存余量，减少拆分数量或先补货 |
| 删除仓库失败 | 仓库中仍有库存记录 | 先将库存迁移到其他仓库，确保仓库为空后再删除 |
| 临期/超龄查询返回空 | 当前无临期或超龄库存，属于正常情况 | 无需处理，不是错误 |
| 自动拆分未找到合适库存 | 所有库存单位的包装数量均无法满足需求 | 检查是否有足够大包装的库存，或手动拆分后重试 |
| 新增库存后找不到记录 | 可能入了临时仓库，筛选条件未包含 | 不指定 warehouseId 筛选，或检查临时仓库 |
