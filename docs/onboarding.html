wkea-cli

给 AI 用的命令行工具。AI 通过它直接操作维嘉后台——建产品、发询价、管订单，不用人工点网页。

⌨️ 15 个模块🪄 150+ 子命令🔧 Commander.js📦 npm wkea-manage-cli

1 这是什么

一句话：这是 AI 的"双手"。以前员工在网页上点按钮操作后台，现在 AI 用命令行一条命令搞定。

大白话：比如 AI 接到任务"给张三家的公司建一个供应商档案"，它不需要去打开浏览器点表单，而是运行 wkea-manage-cli vendor create --name 张三公司 ...，一条命令就把数据写进后台了。wkea-cli 把这些操作封装成 150 多条命令。

谁来用

  • AI 代理（Claude 等）：通过 CLI 操作后台数据，这是主要场景
  • 开发/运维：手动快速查询数据

命令分层

大白话：命令分成三层：外层命令（vendor/product/demand...）→ 中层子命令（create/list/update...）→ 内层参数（--name --price...）。要理解某模块，先跑 <module> guide 看完整说明。

3 核心业务逻辑

3.1 核心命令体系

模块子命令数干什么
vendor27供应商 CRUD、品牌/分类绑定、联系人/银行/发票
product60+SPU/SKU 创建、规格属性绑定、快速创建
demand12需求询价：AI 解析、推供应商、报价
sales-order11销售订单：审核、付款、发货、回库
stock16库存：出入库、拆分、临期、仓库
customer20+客户：地址/发票/银行/联系人
quotation5报价单：创建、加产品、分享

3.2 操作原则（AI 必须遵守）

  1. 先查后改：不确定参数先 --help，枚举用 enum --type 查
  2. 不猜数据：名称/价格/数量必须有来源，禁止捏造
  3. 定价铁律：价格必须来自供应商正式报价，禁止网上搜价填
  4. 写后验证：操作完必须查询确认结果
  5. 给跳转链接：操作完提供后台查看链接

4 新人上手

初始化

npm install
npm run build        # esbuild 打包到 dist/
node dist/index.js init --api-url https://api.wkea.cn --username xxx --password xxx
node dist/index.js --help

常用操作

node dist/index.js vendor guide                 # 看供应商模块说明
node dist/index.js enum --type 供应商类型        # 查枚举
node dist/index.js product quick-create --spu-name "3M口罩" --specs '[...]'
node dist/index.js demand parse --text "需要50个轴承"

新增命令流程

  1. commands/ 对应模块下加命令文件
  2. api/ 加 API 函数
  3. 模块 index.ts 注册
  4. docs/modules/ 同步文档
  5. 跑 npx tsc --noEmit 验证

5 日常维护

任务怎么做
改命令参数commands/ 下改 .option()
后端接口变了api/ 下同步改
发布新版本npm run build → npm publish（记得 .npmignore 只发 dist/）
更新CLI 自带 update 命令：git pull + npm install + build

6 发布

npm run build                    # 打包 dist/
npm run link                     # 本地全局安装测试
npm publish                      # 发布到 npm
注意：提交前必须 npm run build，确保 dist/ 和代码同步。
